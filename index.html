更新日期：2026年06月06日

一、引言

欢迎使用易合随行（以下简称“本应用”）。 本应用由湖州易合天成信息技术有限公司（以下简称“我们”）开发并运营。 我们非常重视用户个人信息与隐私保护，并依据相关法律法规制定本隐私政策。

二、我们收集的信息

为了实现相关功能，我们可能会收集以下信息：

  • 手机号信息
    • 用途：账号注册、身份验证、登录及安全保障。
  • 位置信息
    • 用途：定位服务、位置相关功能及业务服务。
  • 录音权限
    • 用途：语音输入、语音功能实现。
  • 相册权限
    • 用途：上传图片、选择照片作为业务资料。
  • 相机权限
    • 用途：拍照上传、扫码及业务相关功能。
  • 通知权限（POST_NOTIFICATIONS）
    • 用途：在通知栏展示审批提醒、打卡提醒、日程提醒等消息推送。
    • 说明：Android 13 及以上版本首次使用时弹窗申请，用户可随时在系统设置中关闭。
  • 设备推送标识（EMAS DeviceId）
    • 用途：由阿里云 EMAS 移动推送 SDK 生成，用于将用户账号与推送通道绑定，以便服务端精准下发消息。
    • 说明：退出登录时自动解除绑定并从服务器删除该标识。
  • 设备 MAC 地址
    • 用途：由阿里云 EMAS 移动推送 SDK 采集，用于辅助设备唯一性识别与风险防控，不用于追踪用户行为。
    • 说明：仅在用户同意本隐私政策后采集，由阿里云存储于其数据中心。
  • 设备 IMEI（仅 Android 10 以下设备）
    • 用途：由阿里云 EMAS 移动推送 SDK 采集，用于辅助设备唯一性识别。Android 10 及以上系统已无法获取 IMEI，使用其他标识符替代。
    • 说明：仅在用户同意本隐私政策后采集，由阿里云存储于其数据中心。
  • 已安装应用列表（软件列表）
    • 用途：由阿里云 EMAS 移动推送 SDK 采集，用于设备环境安全检测与风险评估，不用于广告推荐或分析用户偏好。
    • 说明：仅在用户同意本隐私政策后采集，由阿里云存储于其数据中心。

三、信息使用方式

我们收集的信息仅用于：

  • 提供和维护产品服务；
  • 优化用户体验；
  • 账号安全验证；
  • 满足法律法规要求。

四、信息共享与披露

未经您的同意，我们不会向第三方出售您的个人信息。 除法律法规要求或监管机构要求外，我们不会向无关第三方披露您的信息。

五、信息存储与保护

我们采取合理的技术和管理措施保护您的个人信息安全， 防止未经授权访问、披露、修改或丢失。

六、您的权利

您有权：

  • 访问您的个人信息；
  • 更正您的个人信息；
  • 删除您的个人信息；
  • 注销您的账号。

七、未成年人保护

若您为未成年人，请在监护人指导下使用本应用。

八、隐私政策更新

若本政策发生重大变化，我们会通过应用内公告等方式通知您。

九、第三方SDK与消息推送说明

本应用集成了以下第三方 SDK，并使用本地通知功能，具体说明如下：

（一）阿里云 EMAS 移动推送 SDK（仅 Android）

项目说明
SDK 名称阿里云移动推送 Android SDK（alicloud-android-push）
SDK 版本3.9.5
服务商阿里云计算有限公司
使用目的向用户推送审批提醒、日程邀请等业务通知
采集的信息
  • 设备标识符：Android ID、OAID，用于生成唯一推送标识（DeviceId）。
  • 设备 MAC 地址：用于辅助设备唯一性识别与风险防控。
  • 设备 IMEI（仅 Android 10 以下设备）：用于辅助设备唯一性识别。
  • 已安装应用列表（软件列表）：用于设备环境安全检测与风险评估，不用于广告目的。
  • 设备基本信息：设备品牌、型号、系统版本，用于适配推送通道。
  • 网络信息：网络连接类型与 IP 地址，用于维持推送长连接。
  • 应用信息：应用包名与版本号，用于推送渠道匹配。
以上信息由阿里云 EMAS SDK 在用户同意隐私政策后采集，存储于阿里云数据中心。
数据传输HTTPS/TLS 加密传输
第三方隐私政策 阿里云隐私政策

本应用使用该 SDK 的具体流程：
① App 启动时 SDK 自动向阿里云注册，生成 DeviceId；
② 本应用将 DeviceId 上报至本公司服务器，与用户账号绑定；
③ 当有审批流转、日程邀请等事件时，服务端通过 EMAS 向对应设备下发通知；
④ 用户点击通知后，App 根据通知参数自动跳转至相关页面；
⑤ 用户退出登录时，本应用自动删除服务器端存储的 DeviceId，解除推送绑定。

（二）本地通知

以下通知由设备本地调度，不经过任何第三方服务器，无数据外传，通知内容仅存储于用户设备本地：

  • 打卡提醒：上班打卡时间前，提醒用户完成打卡；
  • 未打卡提醒：超过打卡宽限时间仍未打卡时提醒；
  • 下班打卡提醒：下班时间到达时提醒用户打卡；
  • 日程提醒：日程开始前按用户设定的时间提前提醒；
  • 待办提醒：有新的待审批或待处理事项时提醒用户。
